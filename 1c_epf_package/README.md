# Внешняя обработка «Пересчёт долей разделки» — пакет исходников

Самодостаточная внешняя обработка (расширение РазделкаДоли не нужно). Форму рисовать вручную не надо:
пакет открывается в Конфигураторе и сохраняется как `.epf`.

**ВНИМАНИЕ:** пакет собран без платформы 1С и не проверялся в Конфигураторе. Если при открытии будет ошибка — пришлите её текст.

## Как получить .epf
1. Распаковать архив в папку (например, `C:\Пересчет`). Структура: `РазделкаПересчетДолей.xml` и рядом папка `РазделкаПересчетДолей`.
2. Конфигуратор (любая база) → «Файл» → «Открыть» → выбрать **`РазделкаПересчетДолей.xml`** (тип файлов: «Внешние обработки, отчёты (*.xml)»).
3. Откроется внешняя обработка с готовой формой. Ctrl+F7 — проверка (она компилируется в контексте базы, к которой
   подключён Конфигуратор; нужна эта база с документом питРазделка).
4. «Файл» → «Сохранить как…» → `РазделкаПересчетДолей.epf`.
5. В 1С:Предприятии: «Файл» (≡) → «Открыть» → выбрать `.epf`.

## Работа
Период (по умолчанию с начала месяца), организация (пусто — все), «Вид цен по умолчанию», «Минимальная доля»
(0 или 0,01), «Только документы, где суммы долей не равны 1» → «Заполнить» → проверить список → «Пересчитать».
Обрабатываются только проведённые документы, каждый перепроводится. Ошибки (закрытый период и т.п.) — в колонке
«Результат», документ остаётся как был. Если в базе есть регистр РазделкаВидЦенПодразделения (из расширения),
вид цен берётся по подразделению документа, иначе — «Вид цен по умолчанию».
