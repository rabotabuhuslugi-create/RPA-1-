ПОЧТА (mail.ru, Яндекс, Gmail…)

Как получить пароль для внешних приложений
  1. mail.ru: Настройки → Пароли и безопасность → «Пароли для внешних приложений» → Добавить (доступ к почте по протоколу IMAP).
  2. Яндекс: Управление аккаунтом → Безопасность → Пароли приложений → Почта.
  3. Gmail: Аккаунт Google → Безопасность → Пароли приложений (нужна двухэтапная проверка).
Обычный пароль от почты не подойдёт.
