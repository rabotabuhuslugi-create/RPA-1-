# Настольный помощник (Google)

Современное окно на весь экран (стекло, градиенты, часы; открывается в Edge/Chrome без адресной строки): **календарь**, **задачи** (Google Tasks), **папки Google Диска**, **почта (Gmail)**.
Уведомления Windows приходят о событиях календаря (за N минут до начала) и о новых письмах.
Помощник работает в фоне и после закрытия окна (уведомления продолжают приходить); повторный запуск ярлыка снова открывает окно, кнопка «Выйти» в настройках останавливает его.
Подключение Google делается кнопками в окне: ⚙ Настройки → загрузить credentials.json → «Подключить Google».

## Установка
    pip install -r assistant/requirements.txt

## Подключение к Google (один раз)
1. https://console.cloud.google.com → создайте проект.
2. «API и сервисы» → «Библиотека» → включите: Google Calendar API, Google Tasks API, Google Drive API, Gmail API.
3. «Экран согласия OAuth» → External → добавьте свою почту в «Тестовые пользователи».
4. «Учётные данные» → «Создать» → «Идентификатор клиента OAuth» → тип **Приложение для ПК** → скачайте JSON,
   сохраните как `credentials.json` в корне проекта.
5. `python -m assistant.app` — откроется браузер, разрешите доступ (только чтение календаря, диска и почты; задачи — чтение/запись).
   Создастся `token.json` (никому не передавайте, он в `.gitignore`).

## Настройки (необязательно) — `assistant_config.yaml`
    default_lead_minutes: 10     # за сколько минут предупреждать, если в событии нет своего напоминания
    calendar_poll_seconds: 60
    mail_poll_seconds: 120
    always_on_top: false
    drive_folders:               # быстрый доступ к нужным папкам (id — из адреса папки в браузере)
      - {name: Договоры, id: 1AbC...}

## Автозапуск в Windows
Win+R → `shell:startup` → создайте ярлык на `pythonw -m assistant.app` (рабочая папка — папка проекта).

## Управление
- Календарь: стрелки — месяцы; двойной клик по событию открывает его в браузере.
- Задачи: ввод + Enter; двойной клик — выполнено; Delete — удалить.
- Диск: двойной клик — войти в папку / открыть файл; список «закреплённых» папок — из конфига.

## Без Google (рекомендуется, особенно из России)
Google Cloud доступен не везде, поэтому всё работает без него:
- **Календарь и задачи** хранятся на компьютере (`assistant_events.json`, `assistant_tasks.json`), напоминания приходят уведомлением Windows.
- **Файлы** — ваши папки компьютера (по умолчанию Документы, Рабочий стол, Загрузки; свои — в ⚙ Настройках). Программы (.exe, .bat и т.п.) отсюда не запускаются.
- **Почта** (mail.ru, Яндекс, Gmail…) — по IMAP: ⚙ Настройки → «Почта» → адрес и **пароль для внешних приложений** (не обычный пароль). Пароль хранится в `assistant_mail.json` на этом компьютере.
