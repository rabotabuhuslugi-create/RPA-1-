# Справочник: объекты 1С КА и данные по ВетИС

Все имена получены из диагностик в реальной базе (не угадывать новые).

## Документы
- `Документ.ВходящаяТранспортнаяОперацияВЕТИС` - реквизиты: ГрузоотправительХозяйствующийСубъект/Предприятие, ГрузополучательХозяйствующийСубъект/Предприятие, ПеревозчикХозяйствующийСубъект, СпособХранения, СерияТТН/НомерТТН/ДатаТТН/ТипТТН, ДокументОснование, Ответственный, ТорговыйОбъект (склад, определяется платформой по предприятию получателя), НомерАктаНесоответствия/ДатаАктаНесоответствия/ПричинаНесоответствия/СерияАктаНесоответствия, ГашениеНаСВХ. ТЧ: Товары (колонка ссылки на ВСД = `ВетеринарноСопроводительныйДокумент`), УпаковкиВЕТИС, ШтрихкодыУпаковок, Маршрут, СвязанныеДокументы, ТоварыУточнение, Регионализация, МаршрутВозврата, СвязанныеДокументыВозврата.
- `Документ.ПриобретениеТоваровУслуг` - НомерВходящегоДокумента, ДатаВходящегоДокумента (именно ее сверяем, не дату документа), НомерСчетаФактуры, Контрагент, Склад, Организация. ТЧ Товары: `КоличествоУпаковок` = **план**, `абр_КоличествоУпаковокФакт` = **факт**, `Количество` (в ед. хранения), `Номенклатура`, `НоменклатураПартнера`.

## Справочники
- `Справочник.ВетеринарноСопроводительныйДокументВЕТИС` (ВСД): Дата, Статус, Закрыт, Грузоотправитель*/Грузополучатель*/Перевозчик*, Продукция, КоличествоВЕТИС, ЕдиницаИзмеренияВЕТИС, СпособХранения, СерияТТН/НомерТТН/ДатаТТН/ТипТТН. ТЧ **СвязанныеДокументы** (ТипДокумента, Серия, Номер, Дата: УПД, ТОРГ-12, Заказ, акты отбора проб). У части поставщиков (например Калашников) связанных документов нет.
- `Справочник.ПродукцияВЕТИС`: Наименование, GTIN, Артикул, ФасовкаУпаковка/КоличествоУпаковок/ЕдиницаИзмерения/КоличествоЕдиницВУпаковке.
- `Справочник.ХозяйствующиеСубъектыВЕТИС`: ИНН, Контрагент (связь с контрагентом 1С), СоответствуетОрганизации.
- `Справочник.ПредприятияВЕТИС`, `ЕдиницыИзмеренияВЕТИС`, `УпаковкиВЕТИС`, `ВЕТИСПрисоединенныеФайлы` (протокол обмена, XML).

## Регистры сведений
- `СтатусыОформленияДокументовВЕТИС`: измерения Документ, Основание; ресурсы СтатусОформления (`Перечисление.СтатусыОформленияДокументовГосИС`: НеОформлено, Оформлено, ЕстьОшибкиОформления…), Архивный. Очередь «К оформлению» = Основание ВСД, статус НеОформлено, не архивный. Если ВСД закрыт/погашен, записи по нему нет.
- `СтатусыДокументовВЕТИС`: Документ, Статус (`Перечисление.СтатусыОбработкиВходящихТранспортныхОперацийВЕТИС`: Черновик, КГашениюВСД, Обрабатывается, Ошибка, ВСДПогашены…), ДальнейшееДействие1..3.
- `СоответствиеНоменклатурыВЕТИС`: Номенклатура, Характеристика, Продукция, Серия, ЗаписьСкладскогоЖурнала; реквизиты Порядок, СтатусУказанияСерий.
- `ШтрихкодыНоменклатуры` (Штрихкод, Номенклатура), `ОчередьСообщенийВЕТИС`, `ИсторияВыполненияОбменовСВЕТИС`, `НастройкиПодключенияВЕТИС`.

## Общие модули и вызовы
- Кнопка «передайте данные»: клиент `ИнтеграцияВЕТИСКлиент.ПодготовитьКПередаче(Форма, ПараметрыПередачи)` -> сервер `ИнтеграцияВЕТИСВызовСервера.ПодготовитьКПередаче(Ссылка, ПараметрыПередачи, УИД)`; параметры `ИнтеграцияВЕТИСКлиентСервер.СтруктураПараметрыПередачи()`, `ДальнейшееДействие = Перечисления.ДальнейшиеДействияПоВзаимодействиюВЕТИС.ПередайтеДанные`.
- Кнопка «Оформить» в списке «К оформлению»: открывает новую операцию с `Основание` = массив ВСД (заполнение по основанию: `Документ.Заполнить(МассивВСД)`). Ключевые реквизиты группы: `ИнтеграцияВЕТИСКлиентСервер.РеквизитыПодбораВСДВоВходящуюТранспортнуюОперацию()`.
- Доработки заказчика с приставкой `пит`: `питИнтеграцияВЕТИС`, `питРасчетСтатусовОформленияВЕТИС`.

## Ошибки Меркурия
- **MERC14235** способ хранения операции не совпадает со ВСД -> группировать по способу хранения и ставить его из ВСД. Меркурий мог принять часть ВСД пакета (подходящие), отклонить остальные.
- **MERC14268** ВСД уже погашен -> операцию не переподавать; в очередь закрытые ВСД не брать.
- **MERC30304** «Отступ превышает количество записей» при запросе изменённых ВСД - служебное, безвредное, если новые ВСД приходят.

## Что выяснено по данным
- Нумерация: форматы различаются (ведущие нули «00ТТ-», префикс «ЦБ-», латинская T вместо Т, суффикс «/18», нули внутри номера). Для части поставщиков (Агрокомплекс, Калашников) номер ТТН не совпадает с УПД - искать по связанным документам, затем по поставщику+складу+дате (ровно один приход).
- Продукция ВетИС за период: 2189 шт., сопоставлена 1; с GTIN 1845, из них 1413 найдены в штрихкодах ровно в одной номенклатуре.
- Операции ЦБ-018, 099, 100 в ошибке: ВСД уже погашены (MERC14268). Операция ЦБ-159: Творог и Коктейль погашены, Масло (другой способ хранения) возвращено в очередь.

## Настройки в модуле (`Настройки()`)
`ДокументВходящаяОперация`, `ПриходПолеПлан=КоличествоУпаковок`, `ПриходПолеФакт=абр_КоличествоУпаковокФакт`, `ПогашатьПослеОформления`, `ОтветственныйНаименование="Финансовый директор"`.
