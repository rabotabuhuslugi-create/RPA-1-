# Расширение 1С: «Рассчитать доли по ценам» (Разделка)

Файлы — исходники BSL; в конфигурацию их надо перенести вручную (в репозитории нет выгрузки
конфигурации, имена метаданных не проверены, места помечены «УТОЧНИТЬ»).

Добавить в расширение:
- общий модуль `РазделкаДоли` (`РазделкаДоли.bsl`);
- константы `РазделкаВидЦенДляРасчетаДолей` (СправочникСсылка.ВидыЦен) и
  `РазделкаМинимальнаяДоляДляПродукта` (Число 3.2, по умолчанию 0);
- регистр сведений `РазделкаВидЦенПодразделения` (измерение Подразделение, ресурс ВидЦен) — по желанию;
- команду и обработчики формы из `ФормаДокументаРазделка.bsl`.

Алгоритм проверен тестами `tests/test_razdelka.py` (`pytest`), включая пример КТЦБ-004740.
Нерешённое в ТЗ: если все строки — «отходы»/без цены, расчёт прерывается с ошибкой (сумма с/с = 1 невозможна).
Список «отходов» сейчас по наименованию — лучше завести признак номенклатуры.

Цены продажи — РС «Цены номенклатуры»; резерв: самая частая из последних цен по розничным видам цен (наименование содержит «озничн»).

При записи документа из формы (Записать / Провести) выводится вопрос «Пересчитать доли…?»:
«Да» — доли рассчитываются, потом документ записывается; «Нет» — запись как есть; закрытие
диалога — запись отменяется. Для «Записать и закрыть» форма после записи остаётся открытой.
Процедура ДолиКорректны в модуле РазделкаДоли больше не вызывается из формы (можно использовать в проведении).

## Сборка расширения (пошагово)
Выполнять на тестовой копии. Платформа 8.3, конфигурация КА 2.x.

1. Конфигуратор → Конфигурация → Расширения конфигурации → Добавить: имя `РазделкаДоли`,
   «Безопасный режим» и «Защита от опасных действий» снять, если не нужны.
2. Общие → Общие модули → Добавить `РазделкаДоли`: флаг «Сервер», без «Вызов сервера»;
   в модуль вставить `РазделкаДоли.bsl`.
3. Константы: `РазделкаВидЦенДляРасчетаДолей` (СправочникСсылка.ВидыЦен),
   `РазделкаМинимальнаяДоляДляПродукта` (Число 3,2; по умолчанию 0 — задать в ПриНачалеРаботыСистемы
   или просто оставить пустым: пустое число = 0).
4. (Необязательно) РС `РазделкаВидЦенПодразделения`: измерение Подразделение, ресурс ВидЦен.
   Если регистр не создаётся — удалить из модуля вызов в функции ВидЦенДляПодразделения.
5. Документ «питРазделка» → Заимствовать объект → форма документа → Заимствовать форму.
   Добавить команду `РассчитатьДолиПоЦенам` и кнопку в командную панель таблицы «Товары» после «Подбор».
   Содержимое `ФормаДокументаРазделка.bsl` вставить в модуль формы.
6. Сверить имена реквизитов (КоличествоФакт, ДоляВыхода, ДоляСебестоимости, Подразделение, Номенклатура)
   с конфигурацией — искать по «УТОЧНИТЬ» и в обработчиках формы.
7. Синтаксический контроль (Ctrl+F7), затем сверка по чек-листу: КТЦБ-004740 → 0,400/0,375/0,225 и 0,43/0,53/0,04.
8. Экспорт: Конфигурация → Расширения → Сохранить в файл (.cfe).

## Сверено по выгрузке Documents/питРазделка.xml
Шапка: Подразделение («Подразделение затрат», СправочникСсылка.СтруктураПредприятия), Номенклатура, Количество,
ТипЦен (строка!), СуммарнаяДоляВыхода. ТЧ «Товары»: Номенклатура, КоличествоНорма, Количество (факт),
ПроцентВыхода (7,3), ПроцентСебестоимости (5,2). Есть ТЧ «ПобочныеИзделия» (Цена, Сумма) — расчётом не затрагивается.
Регистр «РазделкаВидЦенПодразделения»: измерение Подразделение — тип СправочникСсылка.СтруктураПредприятия.
Осталось сверить: форму ФормаДокумента (имя таблицы, место кнопки), модуль объекта (нет ли пересчёта факта при записи).

## Сверено по InformationRegisters/ЦеныНоменклатуры.xml
Периодичность — секунда. Измерения: Номенклатура, Характеристика, ВидЦены (СправочникСсылка.ВидыЦен).
Ресурсы: Цена, Упаковка, Валюта. Запросы РазделкаДоли.bsl используют именно эти имена.
Характеристика — измерение: если у товара цены заданы по разным характеристикам, срез вернёт несколько строк
(в расчёт попадёт последняя); для разделки мяса характеристик обычно нет.

## Сверено по форме питРазделка.ФормаДокумента (Form.xml)
- Таблица `Товары` (Объект.Товары), командная панель `ТоварыКоманднаяПанель`; кнопку добавлять после `ТоварыПодборТовары`.
- Подразделение — поле `ПодразделениеОрганизации` (Объект.Подразделение), дата — `Дата`.
- Видимые колонки: ТоварыКоличествоУпаковок (в упаковках), ТоварыПроцентВыхода, ТоварыПроцентСебестоимости;
  `Количество` (в ед. хранения) и `КоличествоНорма` скрыты. Расчёт берёт `Количество`.
- В форме есть обработчик ТоварыПроцентВыходаПриИзменении (пересчёт факта при ручной правке) — при программной
  записи долей с сервера он НЕ срабатывает. Серверные ПередЗаписьюНаСервере/ПослеЗаписиНаСервере и модуль объекта
  нужно проверить на пересчёт факта по процентам (нужен Module.bsl формы и ObjectModule.bsl).
- Клиентского события ПередЗаписью в базовой форме нет — обработчик из ФормаДокументаРазделка.bsl добавляется в расширении.

## Сверено по Module.bsl формы и ObjectModule.bsl
- Пересчёт факта при правке долей — только клиентский: ТоварыПроцентВыходаПриИзменении → ПересчитатьКоличестваВТабличнойЧасти →
  вопрос «Пересчитать фактические количества?». Программная запись долей с сервера (как в расширении) его не вызывает.
- Серверные ПередЗаписьюНаСервере/ПослеЗаписиНаСервере формы и ПередЗаписью объекта факт не пересчитывают;
  объект лишь считает СуммарнаяДоляВыхода = Товары.Итог("ПроцентВыхода") и проверяет дубли строк (ПроверитьТоварыНаДубли).
- Норма (КоличествоУпаковокНорма/КоличествоНорма) при записи долей расширением НЕ пересчитывается (в стандарте
  она = доля × количество разделываемого товара) — решить отдельно, нужна ли синхронизация нормы.

## Проверка «итого доля себестоимости = 1»
Файл `МодульОбъектаДокумента.bsl` — вставить в модуль объекта документа питРазделка в расширении
(свойства документа → «Модуль объекта» → «Открыть»). Проведение блокируется с сообщением
«Итого доля себестоимости не равна 1, пересчитайте»; простая запись — только предупреждение.
Проверка действует только для операции «Разделка» (питХозяйственныеОперации.РецептураРазделка).
