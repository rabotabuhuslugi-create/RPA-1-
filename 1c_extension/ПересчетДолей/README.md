# Обработка «Пересчёт долей» (групповой пересчёт в старых документах)

Создаётся **внутри расширения РазделкаДоли** (использует его общий модуль, константы и регистр).

## Подготовка
1. Заимствовать в расширение справочник **Организации** (основная конфигурация → Справочники → Организации →
   «Добавить в расширение»).
2. В панели «Разделка доли»: «Обработки» → «Добавить», имя `РазделкаПересчетДолей`, синоним «Пересчёт долей разделки».
3. В модуль объекта вставить `МодульОбъекта.bsl`.
4. Добавить управляемую форму `ФормаПересчета` (основная форма обработки). Реквизиты и команды — см. комментарий в начале
   `МодульФормы.bsl`. На форму поместить: Организация, ДатаС, ДатаПо, ТолькоНеверные, Перепроводить, таблицу Документы
   (колонки Выбор, Документ, Дата, Организация, Проведен, ВыходСейчас, СебестоимостьСейчас, Результат), кнопки
   «Заполнить», «Пересчитать», «Отметить все», «Снять отметки». Код формы — из `МодульФормы.bsl`.
5. Включить обработку в состав подсистемы `РазделкаНастройки` (будет в разделе «Настройки разделки») и дать роли
   `РазделкаДоли_ОсновнаяРоль` права «Использование» и «Просмотр» на обработку.
6. Ctrl+F7, обновить конфигурацию БД, перезапустить 1С.

## Работа
Период и организация → «Заполнить» (по умолчанию только документы, где суммы долей ≠ 1) → проверить список →
«Пересчитать». Проведённые документы перепроводятся (иначе проводки разойдутся с долями); закрытый период или
другие ошибки проведения попадут в колонку «Результат», документ останется как был.
