# Инструкция: расчёт долей в документе «Разделка»

Для кого: сотрудники, которые вводят и проводят документы «Разделка».

## Что делает кнопка
В документе «Разделка» на закладке **«Товары»** появилась кнопка **«Рассчитать доли по ценам»** (справа от «Подбор»). Она сама заполняет две колонки:

- **Доля выхода** — по фактическому весу: вес позиции ÷ общий вес, сумма по документу = 1,000;
- **Доля себестоимости** — пропорционально продажной стоимости (факт × розничная цена), сумма по документу = 1,00.

Кнопка **не меняет** фактическое количество, норму, номенклатуру и порядок строк. Вручную считать доли в Excel больше не нужно.

## Как работать
1. Создайте документ «Разделка», заполните шапку (организация, подразделение, склад, разделываемая номенклатура и количество) и таблицу «Товары» с **фактом** по каждой получаемой позиции.
2. Перейдите на закладку **«Товары»** и нажмите **«Рассчитать доли по ценам»**.
3. Проверьте результат: появится уведомление «Доли рассчитаны» с суммами. Сумма «Доли выхода» должна быть 1,000, «Доли себестоимости» — 1,00.
4. Если выйдет окно **«Нет цены на дату документа»**, проверьте перечисленные позиции (см. ниже) и нажмите кнопку ещё раз.
5. **Запишите** или **проведите** документ.

## Что нужно знать
- **Цены** берутся на дату и время документа по виду цен вашего подразделения. Если для подразделения вид цен не задан, берётся самая частая из розничных цен. Если на дату документа цены нет — у позиции будет доля себестоимости 0,00 и она попадёт в список «Нет цены».
- **Отходы** («Свинина ОТХОДЫ…», «Говядина ОТХОДЫ…», «Курица вода…») всегда получают долю себестоимости 0,00, независимо от цены.
- **Мелкие позиции** (кость, шкура, ноги, сало) могут получить 0,00 из-за округления до сотых. Это нормально.
- **Одна строка в таблице:** доли выхода и себестоимости = 1.
- Нажимайте кнопку **после** того, как внесли весь факт. Если вы изменили факт или добавили строки, нажмите кнопку ещё раз.

## Проведение
Документ **нельзя провести**, если итого доля себестоимости не равна 1. Появится сообщение:

> Итого доля себестоимости не равна 1, нажать кнопку "РАССЧИТАТЬ ДОЛИ ПО ЦЕНАМ"

Нажмите кнопку «Рассчитать доли по ценам» и проведите документ ещё раз. При простой записи (без проведения) сообщение показывается как предупреждение, документ записывается.

## Если что-то не так
| Ситуация | Что делать |
|---|---|
| Кнопки нет | Закройте и заново откройте 1С; если не помогло — сообщите администратору |
| Сообщение «Нет цены на дату документа» | Проверьте, что на дату документа есть розничная цена по этой позиции (регистр «Цены номенклатуры»); сообщите ответственному за цены |
| Доли не равны 1 после расчёта | Сообщите администратору номер документа |
| Ручное изменение «Доли выхода» пересчитывает факт | Это стандартная работа формы: после ручной правки нажмите «Рассчитать доли по ценам» заново |

## Для ответственного за настройки (бухгалтер)
Раздел **«Настройки разделки»** (левая панель, внизу):
- **«Разделка вид цен для расчёта долей»** — вид цен «по умолчанию»;
- **«Разделка вид цен подразделения»** — для каждого подразделения свой вид цен, например «МЦ Каспийская Сочи» → «Сочи 2 кат. Каспийская розничная». Для производственных подразделений без розницы задайте вид цен магазина, куда уходит продукция;
- **«Минимальная доля для продукта с ценой»** — 0 (по умолчанию) или 0,01. При 0,01 каждая продаваемая позиция получает не менее 0,01 себестоимости, лишнее вычитается у самой «дорогой» строки.
