# Массовое копирование закупок (1С:КА 2.5)

Копирует проведённые документы «Приобретение услуг и прочих активов» (или «Приобретение товаров и услуг»)
за выбранный период на новую дату. Счета-фактуры не создаются.

Отборы: организация, контрагент (выпадающие списки), вид документа, флажки «Только без НДС»
(суммы НДС в шапке и табличных частях равны нулю), «Только закупка у поставщика» (хозяйственная операция),
«Очищать входящий номер и дату» (номер и дата документа поставщика у копии сбрасываются).

Сборка: запустите `build_epf.bat` (нужна платформа 1С на этом компьютере), откройте получившийся
`MassCopyPurchases.epf` в 1С через «Файл → Открыть». Двойной щелчок по строке открывает документ.
