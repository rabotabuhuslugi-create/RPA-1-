# Массовое копирование реализаций (1С:КА 2.5)

Обработка берёт проведённые реализации за выбранный период (по умолчанию — прошлый месяц) и создаёт
их копии на новую дату с проведением. Каждая копия — в своей транзакции: ошибка в одном документе не
останавливает остальные, причина видна в колонке «Результат». Повторный запуск дубли не создаёт.

## Как получить файл .epf (без программирования)
1. Скачайте папку `1c` из репозитория (ветка `claude/awesome-hypatia-xg4qk6`) на компьютер с Windows,
   где установлена платформа 1С.
2. Дважды щёлкните `build_epf.bat`. Он сам найдёт 1С, соберёт `MassCopyRealizations.epf` рядом.
   Если не получилось — смотрите `build.log` и пришлите его.
3. Откройте `.epf` в 1С: Файл → Открыть (или Администрирование → Печатные формы, отчёты и обработки →
   Дополнительные отчёты и обработки).

## Первый запуск
Сначала на тестовой копии базы, флажок «Проводить» = Нет. Предполагается тип документа
`РеализацияТоваровУслуг` и реквизиты `Контрагент`, `Организация`, `СуммаДокумента`
(в КА 2.5 они такие, но сборка не проверялась на вашей базе).

## Состав
- `dump/` — исходники обработки в формате выгрузки конфигуратора.
- `build_epf.bat` — сборка `.epf`.
