# Договор подряда со спецификацией — печатная форма к счёту (1С)

Файлы:
- `maket_dogovor_so_specifikaciey.xlsx` — готовый макет (лист «Макет»; лист «Области» — список областей и параметров).
- `ModulObekta.bsl` — модуль объекта внешней обработки, заполняет макет из «Счёт на оплату покупателю» (БП 3.0 + БСП).

## Как собрать
1. Конфигуратор → новая внешняя обработка `ДоговорСоСпецификацией`; код из `ModulObekta.bsl` — в модуль объекта.
2. Добавить макет «Табличный документ» с именем `ДоговорСоСпецификацией`.
3. Открыть xlsx, на листе «Макет» выделить `A1:AG120` (колонки A–AG) → копировать → вставить в макет 1С (Ctrl+V в A1).
4. Назначить имена областей (Таблица → Имена → Назначить имя) по строкам из листа «Области»
   (выделить целые строки; в xlsx справа красным подписано начало каждой области).
5. Для всех ячеек с `[…]`: свойства ячейки → Заполнение → **Шаблон**.
6. Сохранить `.epf` → Администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки →
   добавить файл, «Размещение» → Счёт на оплату покупателю.

Печатается: договор → реквизиты и подписи → (новая страница) Приложение № 1 (спецификация).
