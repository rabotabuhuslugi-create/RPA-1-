# СопоставлениеНоменклатурыВЕТИС — отдельная внешняя обработка

Сопоставляет продукцию ВетИС (из ВСД) с номенклатурой 1С и записывает соответствия в регистр
«Соответствие номенклатуры ВетИС». Не связана с обработкой «МеркурийАвто».

## Сборка (конфигуратор)
1. Файл → Создать → Внешняя обработка, имя `СопоставлениеНоменклатурыВЕТИС`.
2. «Модуль объекта»: вставить `МодульОбъекта.bsl`.
3. Формы → Добавить → имя `ФормаСопоставления` → в модуль формы вставить `КодФормы.bsl`.
4. Свойства формы → События → `ПриСозданииНаСервере` → вписать `ПриСозданииНаСервере`.
5. Свойства обработки → «Основная форма» = `ФормаСопоставления`. Сохранить `.epf`.

## Работа
- «Найти соответствия» — только поиск (ничего не меняет). Статусы:
  Автоматически (GTIN, в том числе без ведущего нуля) / Проверить (артикул, название) /
  Неоднозначно (несколько кандидатов) / Нет кандидата.
- «Примеры существующих» — как выглядят уже имеющиеся записи. Новые пишутся с теми же служебными значениями
  (Порядок, СтатусУказанияСерий — самые частые среди существующих).
- Отметьте нужные строки (или «Выделить автоматические») → «Применить выбранные».
  Запись только в регистр соответствий, в Меркурий ничего не уходит; записи можно удалить из регистра.
