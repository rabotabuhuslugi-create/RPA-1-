# Оприходования без суммы (1С КА 2.5)

## Причина проблемы (по модулям документа «Оприходование излишков товаров»)
В проводках стоимость берётся из колонки строки **«Сумма»** (`ТаблицаТовары.Сумма` → `СуммаУпр` → партии и себестоимость, операция «Внутреннее поступление»).
Цена подставляется только в форме при выборе номенклатуры / кнопкой «Заполнить цены» (`ЦеныПредприятияЗаполнениеСервер.ЗаполнитьЦены` по виду цены документа на его дату).
Нет цены в виде цен — в строке пусто → сумма 0 → в проводках пусто.

## Что делает обработка (приобретения НЕ создаются)
1. Находит проведённые оприходования за период, где в строках `Сумма = 0` при `Количество > 0`.
2. Заполняет `Цена` и `Сумма`: (а) цена в строке есть — Сумма = Цена × Количество; (б) как в форме — `ЗаполнитьЦены` по виду цены документа; (в) если на складе документа цены нет — по учётным видам цен ДРУГИХ складов (флажок «Если на складе нет цены — брать с других складов», перебираются все виды, пока не найдётся цена; в логе указан вид цен); (г) запасной вариант — вид цен закупки из регистра «Цены номенклатуры» (поле на форме, можно пусто). Строки без цены нигде — в логе «НЕТ ЦЕНЫ».
3. Перепроводит документ (в транзакции: при ошибке документ не меняется).
4. Флажок «Перепровести оприходования с расхождениями» — находит документы, где количество не совпадает с регистром «Товары на складах» или сумма — с «Себестоимостью товаров», и перепроводит их.

## Сборка
Конфигуратор (лучше копия базы) → Файл → Открыть → `OprihodovaniyaBezSummy.xml` → Файл → Сохранить как… `.epf`. Или `build_epf.bat`.
Сначала запускать с флажком «Только показать» (по умолчанию включён). Кнопка «Структура документа» — вывод ТЧ и регистров для сверки.

## Проверить в базе
Имя документа `ИмяОприходования()`, имена колонок `Цена`, `Сумма`, `Количество`, реквизитов `ВидЦены`, `Валюта`, регистры `СебестоимостьТоваров` (ресурс `Стоимость`), `ТоварыНаСкладах`, `ЦеныНоменклатуры`.
Платформы 1С в окружении нет — сборка и запуск не проверялись.

## Интерфейс и производительность
- «Организация» и «Вид цен закупки» — выпадающие списки (из справочников; пустой пункт = «все» / «не использовать»).
- Обработка идёт по одному документу: каждый вызов сервера короткий, в строке состояния виден прогресс («документ N из M»), в «Результате» строки добавляются по ходу. Прервать — Ctrl+Break, уже обработанное сохраняется.
- Список учётных видов цен складов собирается один раз за запуск.

## Отчёт об отклонениях
После каждого запуска (и в режиме «Только показать») открывается отчёт, как «Проверка данных», но только строки с проблемами:
Номер, Дата, Склад, Номенклатура, Сумма ТЧ, Сумма ТЧ с НДС, Себестоимость регистр, Себестоимость без НДС, НДС регистр, Расхождение, Проблема.
Проблемы: «Нулевая сумма в ТЧ и регистре», «Нулевая сумма в ТЧ», «Нулевая себестоимость в регистре», «Расхождение суммы ТЧ и регистра».
Себестоимость берётся из регистра «Себестоимость товаров» по (документ, номенклатура); если регистра/полей нет — только строки с нулевой суммой.
Колонки «с НДС» (`ЦенаСНДС`, `СуммаСНДС`) учитываются при исправлении: если Сумма = 0, а «с НДС» заполнено — Сумма берётся оттуда.
Отчёт после обработки показывает, что осталось неисправленным.

Отчёт: двойной щелчок по любой ячейке строки открывает оприходование (расшифровка); шапка закреплена; ширина колонок подобрана под экран.

## Таблица отклонений на форме
При открытии формы кодом создаётся таблица (на всю ширину окна): Документ, Дата, Склад, Номенклатура, Сумма ТЧ, Сумма ТЧ с НДС, Себестоимость регистр, без НДС, НДС регистр, Расхождение, Проблема.
Двойной щелчок или Enter по строке открывает оприходование. Журнал («Результат») — под таблицей. Если таблицу создать не удалось (причина в «Результате»), отклонения откроются отчётом (табличный документ) с расшифровкой по двойному щелчку.

Журнал («Результат») скрыт; появляется сам при «ОШИБКА»/«ВНИМАНИЕ»/«НЕТ ЦЕНЫ» и после кнопки «Структура документа».

## Статусы в таблице
Таблица заполняется ДО обработки и не очищается после: после запуска (не в режиме просмотра) для тех же документов заново считаются значения (Сумма ТЧ, себестоимость, расхождение) и в колонке «Статус после обработки» ставится «Исправлено» / «Не исправлено: <причина> [— ошибка проведения]». Колонка «Было (проблема)» хранит исходную проблему.
Проводки регламентированного учёта (41.01/91.01) после этого нужно заново «Отразить в регл. учёте» — это отдельный шаг КА, обработка его не выполняет.

## Вкладка «2. Проверка количеств (Производство без заказа)»
Показывает (ничего не меняет) отклонения по документу «Производство без заказа», ТЧ «Материалы», как «Атлас»: Склад, Номенклатура, Артикул, Номер/дата, ТЧ, Номер строки, Проблема, Вид/Источник движения, Кол-во в документе/упаковок/в регистре, Расхождение. Двойной щелчок открывает документ.
Проблемы: «Нулевое базовое количество» (Количество = 0, КоличествоУпаковок > 0), «Расхождение: ТоварыНаСкладах» и «Расхождение: СебестоимостьТоваров» (количество по номенклатуре ≠ расходу в регистре, записанному самим документом).
Ограничение: движения по складским ордерам пишет ордер, а не документ — такие строки в проверке видны как «Нет движения (у документа; возможно, по ордеру)».
Период и организация — общие с первой вкладкой. Вкладки и таблица создаются кодом при открытии формы.
