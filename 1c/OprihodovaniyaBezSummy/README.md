# Оприходования без суммы (1С КА 2.5)
Находит проведённые оприходования, где цена есть, а сумма пустая, работает по месяцам (от старых к новым): на каждый месяц и склад создаёт ОДНО «Приобретение товаров и услуг» на начало месяца со всеми такими позициями (по 1 шт. по цене из оприходования, комментарий «Создан автоматически для корректного проведения оприходований»), проводит его и перепроводит оприходования месяца. Повторный запуск дополняет уже созданное автоприобретение, а не плодит новые.

## Сборка .epf
Как у «Сверки актов»: закройте Конфигуратор на КОПИИ базы, запустите `build_epf.bat`, получится `OprihodovaniyaBezSummy.epf`; открыть: «Файл → Открыть».
Исходники: `dump/` (модуль объекта `dump/OprihodovaniyaBezSummy/Ext/ObjectModule.bsl`, модуль формы `.../Forms/Forma/Ext/Form/Module.bsl`).

## Использование
1. Период, организация (часть названия), поставщик и договор для «технических» приобретений.
   Опция «Сначала перепровести оприходования с расхождениями» находит документы, где количество не совпадает с регистром «Товары на складах» или сумма — с «Себестоимостью товаров», и распроводит/проводит их заново (в транзакции: при ошибке документ остаётся проведённым). Затем ищутся оставшиеся строки без суммы.
2. Флажок «Только показать» стоит по умолчанию — сначала посмотрите список в поле «Результат», потом снимите флажок.
3. Кнопка «Структура документа» выводит табличные части и регистры оприходования — для сверки с базой.

## Проверить в базе
Проблемная строка: в документе есть цена или сумма (в любой колонке, в т.ч. «с НДС»), а стоимость в регистре «Себестоимость товаров» по номенклатуре равна 0 или записей нет. Имя документа — `ИмяОприходования()`.
Каждое приобретение добавляет остаток 1 шт. Платформы 1С в окружении нет — сборка и запуск не проверялись.

Режим «Одно приобретение на год» (по умолчанию): блок — календарный год, приобретение датируется 1 января и содержит позиции со всего года (по складу); если снять флажок — блок месяц, дата — 1-е число месяца.
