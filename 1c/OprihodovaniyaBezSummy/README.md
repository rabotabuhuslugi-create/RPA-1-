# Оприходования без суммы (1С КА 2.5)
Исходник `ObjectModule.bsl` — модуль внешней обработки. Форма: период, организация, поставщик, договор, флажок «Только показать», поле лога.
Кнопка вызывает `Выполнить(...)`; кнопка «Структура» — `Структура()` (имена ТЧ и регистров, чтобы свериться с базой).
Проверить в базе: имя документа (`ИмяОприходования()`), условие «сумма пустая» (`С.Сумма = 0`), обязательные реквизиты приобретения.
Побочный эффект: каждое приобретение увеличивает остаток на 1 шт. — как при ручном способе.
Платформы 1С в окружении нет, код не запускался.
