# Внешняя обработка «Массовое копирование реализаций» (1С:КА 2.5)

Берёт ранее созданные проведённые реализации за выбранный период (обычно — прошлый месяц) и
создаёт их копии на новую дату с проведением. Каждая копия — в отдельной транзакции: ошибка в
одном документе не останавливает остальные, причина выводится в колонке «Результат».

## Сборка в конфигураторе
1. Файл → Новый → Внешняя обработка, имя `МассовоеКопированиеРеализаций`.
2. Модуль объекта — содержимое `ObjectModule.bsl`.
3. Добавьте управляемую форму. Реквизиты и команды описаны в шапке `FormModule.bsl`;
   перетащите на форму поля периода, новой даты, организации, контрагента, флажок «Проводить»,
   таблицу `Источники` и кнопки команд. Код формы — из `FormModule.bsl`.
4. Сохраните как `.epf`. Подключение: Администрирование → Печатные формы, отчёты и обработки →
   Дополнительные отчёты и обработки (или Файл → Открыть).

## Что проверить под вашу базу
- Тип документа `РеализацияТоваровУслуг` и реквизиты `Партнер`, `Контрагент`, `Организация`,
  `СуммаДокумента` — по структуре конфигурации.
- Копия сохраняет цены источника. Если цены меняются по соглашению — добавьте перезаполнение цен.
- Если в источнике заполнена ссылка на заказ клиента, копия сохранит её; при необходимости очистите
  в `СоздатьКопию`.
- Сначала прогоните на тестовой копии базы с флажком «Проводить» = Нет.
