# МеркурийАвто — внешняя обработка 1С

1. В конфигураторе: Файл → Создать → Внешняя обработка, имя `МеркурийАвто`.
2. Откройте «Модуль объекта» и вставьте `МодульОбъекта.bsl`.
3. Добавьте форму с кнопками (или вызывайте из консоли кода) `Диагностика()` и `Выполнить(...)`.
4. Запустите `Диагностика()` и пришлите результат — по нему впишем точные имена и штатные
   вызовы «оформите» / «отработайте».
5. Пробный прогон: `Выполнить(Истина)`. Боевой — только после проверки, пакетами по 50 и за свежий период.

Что нужно ещё: в конфигураторе откройте обработку/форму «Обмен с ВетИС» (рабочее место),
найдите обработчики гиперссылок «оформите» и «отработайте» и пришлите имена процедур, которые они вызывают.
Это единственное место, где остаётся заглушка.

Важно: гашение ВСД необратимо и уходит в ГИС «Меркурий». 39 609 старых записей автоматически
не трогаем — по умолчанию период с 01.09, лимит пакета 50.


## Рабочее место сотрудника (форма ФормаСотрудника)
1. Модуль объекта обработки: замените текстом из `МодульОбъекта.bsl`.
2. Формы -> Добавить -> имя `ФормаСотрудника` -> Готово. Откройте модуль формы, удалите все и вставьте `КодФормыСотрудника.bsl`.
   Поля, кнопки "Проверить" / "Оформить и отправить" и таблица создаются кодом при открытии.
3. Свойства обработки -> "Основная форма" -> `ФормаСотрудника`. Старую форму можно оставить для разработчика.
4. Сохранить как .epf. В 1С: Файл -> Открыть -> этот файл.

Таблица: статус (Готово / Расхождение / Нет прихода), вид ошибки и подробности, накладная, отправитель,
получатель, число ВСД, количества по ВСД и по поступлению, поступление, операция ВетИС, результат.
"Проверить" ничего не меняет. "Оформить и отправить" оформляет первые N накладных со статусом "Готово"
(N - поле "Оформить за один раз") и передает их на гашение; передача необратима.
