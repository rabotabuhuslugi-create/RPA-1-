# МеркурийАвто — внешняя обработка 1С

1. В конфигураторе: Файл → Создать → Внешняя обработка, имя `МеркурийАвто`.
2. Откройте «Модуль объекта» и вставьте `МодульОбъекта.bsl`.
3. Добавьте форму с кнопками (или вызывайте из консоли кода) `Диагностика()` и `Выполнить(...)`.
4. Запустите `Диагностика()` и пришлите результат — по нему впишем точные имена и штатные
   вызовы «оформите» / «отработайте».
5. Пробный прогон: `Выполнить(Истина)`. Боевой — только после проверки, пакетами по 50 и за свежий период.

Что нужно ещё: в конфигураторе откройте обработку/форму «Обмен с ВетИС» (рабочее место),
найдите обработчики гиперссылок «оформите» и «отработайте» и пришлите имена процедур, которые они вызывают.
Это единственное место, где остаётся заглушка.

Важно: гашение ВСД необратимо и уходит в ГИС «Меркурий». 39 609 старых записей автоматически
не трогаем — по умолчанию окно 30 дней, лимит пакета 50.
