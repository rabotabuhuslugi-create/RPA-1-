# Задание 1С-программисту: автоматизация оформления и гашения ВСД (ВетИС / Меркурий)

## Цель
В базе 1С:Комплексная автоматизация, экран «Обмен с ВетИС (Меркурий)», по организации ООО «КУБАНЬТОРГ»
накопилось: «Входящие транспортные операции ВетИС» — 39 612, из них «оформите» — 39 609,
«отработайте» — 2, «ожидайте» — 1. Нужно автоматически оформлять поступления и гасить входящие ВСД,
чтобы не делать это вручную.

## Что нужно сделать (этап 1, без изменения конфигурации)
Файлы в архиве: `МодульОбъекта.bsl` — заготовка внешней обработки «МеркурийАвто».

1. В конфигураторе создать внешнюю обработку `МеркурийАвто`, вставить `МодульОбъекта.bsl` в модуль объекта.
2. Добавить форму с кнопкой «Диагностика» (вызывает `Объект.Диагностика()` на сервере, результат — в текстовое поле или `Сообщить`).
3. Запустить диагностику в базе (лучше сначала в копии) и прислать вывод текстом.
4. Открыть модуль формы обработки/рабочего места «Обмен с ВетИС» и найти обработчики гиперссылок
   «оформите» и «отработайте». Прислать их текст и имена вызываемых процедур
   (ожидается общий модуль `ИнтеграцияВЕТИС*` / `ИнтеграцияВЕТИСВызовСервера`).
5. Сверить `Настройки()` в модуле с реальными именами объектов и поправить.
6. Реализовать `ОформитьИПогасить(Ссылка)` штатными вызовами из п.4 и условие отбора в `ОчередьОформления`
   (только еще не оформленные записи).

## Требования
- Режим пробного прогона (`Выполнить(Истина)`), по умолчанию — ничего не оформляется и не гасится.
- Ограничение по периоду (по умолчанию с 01.09) и размер пакета (по умолчанию 50). Все 39 609 старых записей
  автоматически НЕ обрабатывать — гашение ВСД необратимо и уходит в ГИС «Меркурий».
- Ошибки по каждой записи — в журнал регистрации, цикл не прерывать.
- Поддержка отбора по организации.
- Код оставлять в модуле объекта без форм-зависимостей: на втором этапе его переносят в общий модуль
  расширения и запускают регламентным заданием.

## Что вернуть
Готовый файл `МеркурийАвто.epf` (или текст модуля) и вывод диагностики.
