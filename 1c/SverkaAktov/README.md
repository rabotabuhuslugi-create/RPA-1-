# Сверка актов сверки с поставщиком (внешняя обработка 1С)

Обработка сравнивает **акт сверки из 1С** («наш») с **актом поставщика** (Excel, CSV или Word) и показывает:
сальдо начальное и конечное, расхождения по сальдо, документы, которые совпадают, расходятся по сумме,
есть только у нас или только у поставщика. Алгоритм перенесён из веб-сервиса «Сервис сверки актов — Профессиональная версия».

## Как собрать .epf
1. Закройте Конфигуратор на базе, в которой собираете.
2. Запустите `build_epf.bat` (подключение к базе берётся из `build_settings.ps1`; если файла нет — спросит).
3. Получится `SverkaAktov.epf`. Открыть: «Файл → Открыть» в 1С:Предприятии.

## Как пользоваться
1. **Наш акт** — по умолчанию формируется из документа **«Сверка взаиморасчётов»**: создайте документ (организация, контрагент, период), нажмите «Заполнить», запишите,
   затем выберите его в обработке в поле «Документ сверки взаиморасчётов». Из выпадающего списка выберите договор с поставщиком (пусто — все договоры расчётов с поставщиками).
   Обработка читает «Детальные записи» документа (дата, документ, номер, связанные документы — счета-фактуры, дебет, кредит) и сальдо начальное и конечное из итогов.
   Названия колонок документа определяются автоматически по метаданным; если не нашлись — выводится структура документа для настройки.
   Кнопка «Структура документа сверки (для настройки)» показывает документы, регистры и справочники расчётов вашей конфигурации.
   Если формирование не подошло — переключите источник на **«Из файла»**: распечатайте «Акт сверки взаимных расчётов», сохраните в Excel и выберите файл.
2. **Акт поставщика** — файл (xlsx, xls, csv, docx, mxl). После выбора обработка сама находит шапку, первую строку данных и колонки (дата, документ, дебет, кредит);
   номера колонок можно поправить. Под файлом показана первая строка данных — проверьте, что это «Сальдо начальное».
3. Выберите **метод сравнения**: «Дата + Номер + Сумма», «Номер + Сумма», «Дата + Сумма» или «Только сумма».
4. Нажмите **«Сверить»**. Внизу — таблица результата, цветом подсвечены статусы; фильтр «Показать» оставляет нужный статус.
5. **«Сохранить в Excel»** — выгрузка итогов и таблицы.

## Что делает сверка
- **Сальдо.** Начальное и конечное сальдо берутся из строк «Сальдо начальное / конечное» файла; если конечного нет — считается (начальное + обороты).
  Сальдо сравнивается по модулю (долг у одной стороны — переплата у другой). У поставщика дебет и кредит зеркальны, обработка их учитывает.
- **Сопоставление строк.** По выбранному методу; номер документа берётся из текста («Приобретение №2462 (Счёт-фактура №24462)» → 24462 и 2462,
  приоритет у номера счёта-фактуры/УПД); дата — «от ДД.ММ.ГГГГ» из текста, иначе из колонки.
- **УКД и корректировки** сопоставляются зеркально (дебет у нас = кредит у поставщика).
- **Групповое совпадение:** одна запись у нас = несколько у поставщика (и наоборот) с тем же номером и суммой в сумме.
- **Расхождения:** тот же документ, но разная сумма; предупреждение, если номер СФ расходится.
- Подписи, реквизиты и итоговые строки акта отбрасываются автоматически.

## Отличия от веб-сервиса
- Нет «ИИ-автоопределения» колонок через Claude — вместо него обычное автоопределение по заголовкам и содержимому.
- Файлы читаются с компьютера пользователя; Excel — штатным чтением табличного документа 1С, DOCX — самая большая таблица документа.
- Работает в тонком клиенте. Не проверялось в веб-клиенте.
