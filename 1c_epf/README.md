# Внешняя обработка «РазделкаДолиПоЦенам»

Файл .epf здесь не собран (нужна платформа 1С). Сборка в Конфигураторе:
1. Файл → Новый → Внешняя обработка, имя `РазделкаДолиПоЦенам`.
2. Вставить `МодульОбъекта.bsl` в модуль объекта.
3. Добавить управляемую форму, реквизиты и команды — по комментарию в начале `МодульФормы.bsl`,
   код вставить в модуль формы. Перетащить на форму Документ, ВидЦен, МинДоля, Отходы (по умолчанию:
   «Свинина ОТХОДЫ», «Говядина ОТХОДЫ», «Курица вода»), таблицу Предпросмотр и обе команды.
4. Сохранить как .epf.

Работа: выбрать документ → «Рассчитать» (смотрим таблицу) → «Применить к документу» →
открыть документ, проверить, провести. Проведённый документ обработка не меняет.
Отличия от расширения: нет кнопки в форме документа и проверки перед проведением;
настройки вводятся на форме, а не в константах. Тесты алгоритма — tests/test_razdelka.py.
