# Контроль инкассации (внешняя обработка 1С:КА)

Отчёт: РКО «Инкассация в банк» ↔ поступление на счёт, с проверкой графика.

## Установка
1. Конфигуратор → Файл → Новый → Внешняя обработка, имя `КонтрольИнкассации`.
2. Добавить **управляемую форму** (оставить пустой, основной).
3. Открыть модуль формы, вставить **весь** текст `МодульФормы.bsl`, сохранить как `.epf`.
4. В функции `Настройки()` проверить имена (регистр, документы, реквизиты) под вашу базу.
5. Запустить в режиме 1С:Предприятие: Файл → Открыть → `.epf`.

## Работа
1. Вкладка «Загрузка списка»: вставить из Excel таблицу «Организация | СВ | Магазин | День инкассации»
   (как у вас: `пнд`, `пнд чтв`, `с/инк`, `закрыт`) → «Загрузить список в графики».
   Касса находится по названию «<Магазин> Основная…» и организации; что не нашлось — остаётся в поле
   ввода (такие кассы добавьте руками на вкладке графиков). «СВ-пнд» читается как понедельник.
2. Вкладка «Графики инкассации» — **график редактируется вручную**: флажки Пн–Вс, «С/инк», «Закрыт»,
   добавить/удалить строку. «Добавить кассы из движений» подтягивает кассы с инкассацией за 120 дней.
   После правки — «Сохранить графики».
3. Вкладка «Отчёт» → период → «Сформировать».

Особые режимы: **с/инк** — любой день допустим, пропуски не проверяются; **закрыт** — пропуски не
проверяются, а РКО по такой кассе будет жёлтым; пустой график — жёлтым «дни не заданы».

Важно: графики хранятся в `ХранилищеОбщихНастроек` **текущего пользователя**. Если отчётом будут
пользоваться несколько человек, графики нужно либо вносить каждому, либо перенести в регистр сведений
в конфигурации (скажете — сделаю).

## Правила (по ТЗ)
- Пара РКО ↔ поступление: по номеру сумки (в РКО «Номер сумки», в поступлении «Номер по банку»,
  либо номер из назначения платежа «…ведомости №…»; ведущие нули не учитываются). Если номера нет —
  та же касса, та же сумма, в окне до 3 календарных дней.
- 🟢 ОК — пара найдена, сумма совпала, срок ≤ 3 дн., сдача в день графика.
- 🟡 Вне графика — всё сошлось, но день не из графика (или кассы нет в графике). Самоинкассация — те же документы.
- ⚪ В пути — поступления нет, но 3 дня ещё не прошли.
- 🔴 Нет поступления > 3 дн.; Расхождение суммы; Позже срока; Поступление без РКО; Пропуск дня графика.

## Что проверить при первом запуске
- Имена реквизитов `НомерСумки`, `НомерПоБанку`, `НазначениеПлатежа` и документа поступления — угаданы,
  при ошибке запроса 1С назовёт неверное имя.
- Тип регистра: измерение `Отправитель` должно быть кассой, а получатель — счётом (как на скриншотах).
- Сверить итоги с вашим отчётом «Денежные средства в пути» за октябрь (остаток 192 000; Калинина 280 000
  должна быть красной «Нет поступления», Дарвина/Гомельская 3 — расхождение суммы).
