# RPA: загрузка сканов документов в 1С:Комплексная автоматизация

Поток: папка `inbox` → OCR (Xiaomi-OCR-0 0.8B через Ollama, запасной — Tesseract) → извлечение номера, даты, ИНН/КПП, суммы, НДС →
поиск контрагента и договора в 1С → создание документа «Приобретение товаров и услуг»
(черновик или проведённый) → скан прикрепляется к документу → файл уходит в `processed`
(или в `errors` вместе с `.error.json`).

Для Windows см. [INSTALL_WINDOWS.md](INSTALL_WINDOWS.md).

## Быстрый старт для пользователя (Windows)
1. Установите [Ollama](https://ollama.com/download/windows).
2. Двойной щелчок по `start.bat` (первый раз он сам установит всё нужное) — откроется панель в браузере.
3. Вкладка «Настройки»: нажмите «Скачать модель», введите адрес/логин/пароль 1С, «Сохранить», «Проверить связь с 1С».
4. Перетащите сканы во вкладку «Загрузка сканов» (или кладите в папку `inbox`).
Для готового `RPA1C.exe` без Python запустите `build_exe.bat` один раз на любом Windows-компьютере.
Пароль 1С хранится в `config.yaml` на этом компьютере открытым текстом — не копируйте файл посторонним.

## Установка (для администратора)
1. Python 3.10+, `pip install -r requirements.txt`
2. Установить [Ollama](https://ollama.com) и скачать модель Xiaomi-OCR-0 (`ollama pull <имя с страницы модели>`;
   имя пропишите в `ocr.xiaomi.model`). Tesseract OCR нужен только как запасной вариант с русским языком (и Poppler для PDF).
3. В 1С опубликовать стандартный интерфейс OData и включить нужные объекты в состав.
4. `cp config.example.yaml config.yaml`, заполнить; пароль: `export ONEC_PASSWORD=...`

## Запуск
    python -m rpa1c.main --dry-run   # только распознавание, 1С не трогаем
    python -m rpa1c.main             # боевой режим (цикл по poll_seconds)
    python -m rpa1c.main --dashboard # то же + веб-панель http://127.0.0.1:8765 (откроется в браузере)
    python -m rpa1c.dashboard        # только панель (смотреть историю, когда робот не запущен)
    pytest                           # тесты парсера

## Важно проверить под вашу базу
- Имена сущностей и реквизитов смотрите в `<base_url>/$metadata` (имена в `config.yaml` и
  `rpa1c/onec.py` — типовые для КА 2.x и могут отличаться).
- Загрузка файла: поле `attachment_data_field` зависит от конфигурации; если OData не принимает
  двоичные данные, пишите файл через HTTP-сервис 1С или COM.
- Обязательные реквизиты документа добавляйте в `extra_document_fields`.
- Сначала держите `post_document: false` и проверяйте черновики вручную.
- Шаблоны regex в `rpa1c/parser.py` рассчитаны на типовые счета/УПД; под ваших поставщиков доработайте.

## Панель управления
Показывает в реальном времени: статус робота, текущий документ и этап (OCR → разбор → создание
в 1С → прикрепление скана), очередь, ошибки, историю документов и журнал. Из панели можно
загружать сканы (перетаскиванием), ставить робота на паузу и повторять файлы с ошибками.
Панель слушает только `127.0.0.1` (без пароля), поэтому не открывайте её в сеть (`host: 0.0.0.0`)
без дополнительной защиты. Данные хранятся в папке `state/`.
