# Автоматическое подтверждение ЭТрН в 1С-ЭПД (КА 2.5 / ERP 2.5)

Цель: внешняя обработка (.epf), которая находит входящие ЭТрН в состоянии
«Приемка — Требуется подписание» и подписывает их штатным механизмом 1С-ЭПД
с вашей ЭЦП (без кликов по интерфейсу).

## Этап 1 — разведка (сделать сейчас)
Точные имена объектов/общих модулей ЭПД различаются между релизами БЭД,
угадывать их нельзя: код подписания зависит от них.

1. Конфигуратор → Файл → Новая → Внешняя обработка, имя `РазведкаЭПД`.
2. Добавить управляемую форму (пустую), вставить в её модуль `Форма_РазведкаЭПД.bsl`.
3. Сохранить `.epf`, открыть в 1С (Файл → Открыть, режим 1С:Предприятие), нажать кнопку.
4. Прислать текст из поля (список объектов ЭПД: документы, регистры, перечисления
   статусов, общие модули) — и желательно версию БЭД (Справка → О программе).

## Этап 2 — основная обработка (после разведки)
- Отбор: организация, контрагент, период, статус «Требуется подписание».
- Таблица найденных ЭТрН с флажками, пометка «Подписать все».
- Подписание через серверный API ЭПД/БЭД (сертификат из хранилища пользователя;
  подпись ставится на клиенте — это требование КриптоПро, поэтому пакетный режим
  работает в открытой сессии 1С).
- Журнал результата по каждой ЭТрН, режим «только показать» (пробный прогон).
