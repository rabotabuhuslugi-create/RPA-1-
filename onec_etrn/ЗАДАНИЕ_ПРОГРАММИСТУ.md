# Автоподтверждение входящих ЭТрН (шаг «Приемка») — что нужно от программиста 1С

База: 1С:Комплексная автоматизация 2.5.22.137, подсистема 1С-ЭПД (БЭД).
Цель: подписывать и отправлять титул грузополучателя («Приемка», результат «Принят») для входящих ЭТрН
без ручных действий. Сейчас вручную: список «Электронные перевозочные документы» → документ → шаг «Приемка» →
«Принят» → кнопка «Отправить» (подпись ЭЦП).

Что уже известно (получено разведкой):
- Документ `ЭлектроннаяТранспортнаяНакладная`: `ЭтоВходящий`, `ТекущийШаг` (строка: Оформление/Приемка/Разгрузка),
  `ТекущийШагВыполнен`, `ТекущийТитул` и `ТекущийПолученныйТитул` (`Перечисление.ТипыЭлементовРегламентаЭДО`),
  `РольУчастника` (=2), `Организация`.
- Нужны документы: `ЭтоВходящий` = Истина, `ТекущийШаг` = «Приемка», `ТекущийШагВыполнен` = Ложь,
  `ТекущийТитул` = «Информация грузополучателя» (сейчас таких 88).
- Общие модули: `РегламентыЭПД_ЭТрН`, `ОбменСГИСЭПД`, `ОбменСГИСЭПДВызовСервера`, `ОбменСГИСЭПДКлиент`,
  `ОбменСГИСЭПДКлиентСервер`, `ОбменСГИСЭПДСлужебный`, `ТранспортныеКонтейнерыЭДО*`.
- Регистры `РеестрЭПД`, `ВерсииТитуловЭПД`. Обработки `ГрупповаяОтправкаЭПД`, `ЭлектронныеПеревозочныеДокументы`.
