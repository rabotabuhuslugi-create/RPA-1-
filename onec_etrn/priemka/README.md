# Приёмка ЭТрН — внешняя обработка (сборка 1)
Сборка: `Собрать_epf.bat` → `PriemkaETRN.epf`, открыть в 1С через Файл → Открыть.

Что делает сейчас:
- «Заполнить список» — входящие ЭТрН на шаге «Приемка» с невыполненным титулом грузополучателя за период.
- Колонки: места и масса брутто у отправителя и в нашем (черновом) титуле; «Проверка»: ОК / расхождение / нет данных.
- Двойной щелчок по строке открывает документ.
- «Подписать и отправить выбранные» — заглушка, пока не известна процедура подписания 1С-ЭПД
  (точка подключения `ПодписатьИОтправитьТитул` в модуле формы). Данные не изменяются.
