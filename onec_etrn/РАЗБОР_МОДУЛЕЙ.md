# Что выяснено из модулей (ЭТрН, КА 2.5.22.137)

Источник: модуль объекта и модуль формы `ОсновнаяФорма` документа `ЭлектроннаяТранспортнаяНакладная`.

- Кнопка «Отправить» → `ОтправитьЧерезЭДО` → `ОбменСГИСЭПДКлиент.ОтправитьЭПД(ЭтотОбъект(форма), ВводимИсправление, Повторно)`.
  Это клиентский вызов, которому передаётся сама ФОРМА; после отправки форма в `ПослеВыполненияДействийПоЭДО` вызывает `Записать`.
- «Проверить» → `ЗаполнитьУчастников()` + `ОбменСГИСЭПДКлиент.ЗаполнитьИдентификациюФайлаОбмена(форма, ПрефиксТитула, ИдентификаторОтправителя())`.
- Данные титулов хранятся в регистре `ЗначенияРеквизитовДокументовЭПД`, версии файлов в `ВерсииТитуловЭПД`
  (пишет `ПриЗаписи` объекта из `ДополнительныеСвойства.СтруктураРеквизитов`). Значения в форму/из формы идут через
  `ОбменСГИСЭПДКлиентСервер.УстановитьЗначениеРеквизитаВСтруктуреФормы(Форма, Имя, Значение, ...)`.
- Для титула грузополучателя (`ЭТрН_Титул3`) 1С сама ставит по умолчанию: содержание операции, метод массы «03»,
  фактические дата/время прибытия и убытия = текущее время сеанса, округлённое (`ОкруглениеДатыПриИзменении`),
  заявленное прибытие из данных отправителя, адрес выгрузки. НЕ ставит: количество принятых мест, массу брутто принятого груза,
  фактическое состояние груза — их вводит человек. «Результат приёмки» — реквизит формы `ВариантПриемки` (2 = отказ, иначе принят).
- Подпись ЭЦП выполняется подсистемой ЭДО на клиенте (КриптоПро на рабочем месте пользователя).

Вывод: автоматизировать надо через реальную форму документа (открыть форму, заполнить 3 поля, вызвать тот же `ОтправитьЭПД`).
Нужны тексты: `ОбменСГИСЭПДКлиент`, `ОбменСГИСЭПДКлиентСервер`.
