# Правила приёмки ЭТрН (из инструкции пользователя «Инструкция_ЭТрН_Приемка»)

Какие документы: шаг «Приёмка», состояние «Требуется подписание» (в данных: ЭтоВходящий, ТекущийШаг=«Приемка»,
ТекущийШагВыполнен=Нет, ТекущийТитул=«Информация грузополучателя»).

Заполнение шага «Приёмка»:
| Поле | Правило |
|---|---|
| Результат приёмки | «Принят» |
| Фактические дата и время прибытия ТС / убытия | фактические значения |
| Заявленные дата и время прибытия | автоматически, только проверить |
| Метод определения массы груза | из списка (например, «Расчётная масса груза») |
| Общее количество принятых грузовых мест | из таблицы «Сведения о грузе» (этап «Погрузка») |
| Фактическое состояние груза | обязательно, например «Груз принят в полном объеме» |
| Масса брутто принятого груза, кг | фактическое значение (из «Сведений о грузе») |
| Масса нетто принятого груза, кг | НЕ заполнять |
| Объём грузовых мест, м3 | НЕ заполнять |
| Адрес места выгрузки | подгружается автоматически, проверить |

Завершение: «Проверить» (нет ошибок) → «Отправить» (подпись ЭЦП, шаг переходит к «Разгрузка»).

Правила для автоматизации: документ пропускается и попадает в журнал «нужна ручная проверка», если количество мест
или масса брутто пусты/равны нулю, «Проверить» вернула ошибку или ЭЦП не подтверждена.
