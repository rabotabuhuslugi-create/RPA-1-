# Обработка «Закрытие периода: проверки»

Внешняя обработка 1С (управляемая форма) в исходниках формата выгрузки конфигуратора (v2.11).
Ориентир по конфигурации — ERP / КА 2 (объекты `СчетФактураПолученный`, `ДвиженияПоНДС`,
`КорректировкаПриобретения`, `СписаниеНедостачТоваров`, `Справочники.Организации`, регистр `Хозрасчетный`).

## Как собрать .epf

```bash
1cv8 DESIGNER /LoadExternalDataProcessorOrReportFromFiles "ЗакрытиеПериода.xml" "ЗакрытиеПериода.epf" /Out load.log
```

или в конфигураторе: Файл → Открыть → выбрать `ЗакрытиеПериода.xml` (при необходимости сохранить как .epf).

## Вкладки

| Вкладка | Что проверяет |
|---|---|
| Сводка | Результат всех проверок: сколько найдено, статус |
| Нет проводок | Проведённые документы без проводок в Хозрасчётном |
| Нет проводок по счёту | То же по выбранному счёту и виду документа |
| СФ без движений НДС | Полученные СФ без движений в `ДвиженияПоНДС` |
| Дубли проводок | Одинаковые проводки в документе (по заданным Дт/Кт) |
| Дубли СФ | На документ оформлено больше одного СФ |
| СФ и исправления | СФ по документам, исправленным корректировкой «Исправление ошибок» |
| Удалённые с движениями | Помеченные на удаление документы с движениями |
| Суммы списаний в РУ | Оборот по счёту больше суммы документа (коэфф. настраивается) |
| Непроведённые документы | Все непроведённые за период |
| Сверка деклараций НДС | Сравнение книг покупок (разд. 8) двух деклараций из данных 1С, повторы СФ, дубли, экспорт |

Двойной щелчок по строке открывает документ. На вкладках с документами есть кнопки
«Провести / перепровести (по датам)» и «Очистить движения (проведение сохраняется)» — очистка
сознательно не снимает проведение, чтобы массовое перепроведение шло без лишней нагрузки.

Чтобы добавить проверку: описать её в `ОписаниеПроверок()` и добавить ветку в `ВыполнитьПроверкуПоИмени()`.

> Исходники не проверялись на платформе 1С (её нет в среде разработки). При первой загрузке
> возможны правки синтаксиса/метаданных под вашу конфигурацию — ошибки конкретной проверки
> не блокируют остальные (выводится сообщение и статус «Ошибка выполнения»).
